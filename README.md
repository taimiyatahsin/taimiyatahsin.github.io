# Taimiya Tahsin — Portfolio

Personal portfolio website for **Taimiya Tahsin**, a Computer Science and Engineering student from Bangladesh interested in Artificial Intelligence, Machine Learning, research, and cybersecurity.

## Live website

- **GitHub Pages:** https://taimiyatahsin.github.io/
- **Cloudflare Pages:** https://taimiyatahsin-portfolio.pages.dev/

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive layout for desktop and mobile
- Light and dark theme toggle
- System theme preference with locally saved selection
- Animated introduction with reduced-motion support
- About, skills, interests, and contact sections
- Social profile links and accessible navigation
